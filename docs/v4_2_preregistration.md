# v4.2 H4/H2 validation preregistration

v4.2 is a constrained validation of the v4.1.1 release. It preserves every v4.1 conclusion. H4 first audits whether raw WearGait walkway streams contain calibrated timing and footfall geometry sufficient to reconstruct all eight frozen PKMAS-compatible inputs. It stops as `NOT_ESTIMABLE` if V1 analytical equivalence cannot be established for every input; no partial score or threshold relaxation is permitted.

H2-R uses 100 prespecified seeded participant-grouped five-fold repeats, then participant aggregation, nested ridge, and ordinal proportional-odds sensitivities. The baseline and extended predictor sets are unchanged from v4.1. The original H2 remains not established even if ranking support proves stable.
