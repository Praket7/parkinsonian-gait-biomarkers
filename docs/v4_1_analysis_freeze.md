# v4.1 analysis freeze

Protocol version: `4.1.0`. Parent release: `v4.0.6`. The content-addressed manifest is created before scripts access clinical outcomes. Frozen choices are the eight input order, control-only reference, sample and Ledoit-Wolf covariance methods, five grouped folds, 2,000 control-reference and held-out-participant resamples, eight leave-one-out analyses, and 200 Mobilise-D participant-half resamples.

The release contains aggregate tables only. Participant identifiers, row-level predictions, source paths, and raw data are excluded.
