# v5.0.0 AAN submission release

This release consolidates the project into a single, judge-facing report and abstract and adds traceable evidence tables, literature context, six aggregate-only figures, authorship disclosure, and automated submission checks.

The underlying frozen scientific results were not rerun or changed for this release. The report incorporates the v4.5 endpoint correction and preserves earlier analyses for provenance. Participant-level data remain outside this public repository.

The principal conclusion is unchanged: the frozen score supports severity association, reference robustness, incremental ranking, and the eight-input WearGait analytical bridge. It did not meet the six-plus-month stability criterion. Short-term reliability, clinical responsiveness, medication response, and broad external transport remain not estimable.

The abstract and report are AI-assisted drafts. A student applicant must independently write the final submission in their own words, verify and understand every claim, disclose assistance as required, and obtain required signatures. See [authorship and assistance](AUTHORSHIP_AND_ASSISTANCE.md).
