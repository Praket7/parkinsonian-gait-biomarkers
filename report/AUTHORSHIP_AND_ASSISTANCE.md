# Project contributions and computational assistance

This file records the contribution boundaries that are visible from the repository and project history. It is intended to support accurate attribution and should not be treated as a certification of authorship.

## Research direction

The student defined and refined the project goals, selected the scientific questions to pursue, authorized the use of the datasets, reviewed the interpretations, and directed revisions to the analysis and presentation.

The repository alone cannot establish who independently performed every research, coding, or writing task. Claims about individual contribution should therefore be made only when they can be verified by the student and any supervising mentor.

## Mentor contribution

No specific mentor contribution is documented in the repository. Any advice on study design, data access, analysis, interpretation, or presentation should be recorded accurately before an external submission.

## Computational assistance

Codex was used for parts of repository implementation, source-schema auditing, analysis scripting, aggregate-result checks, figure generation, documentation editing, and quality assurance. The analysis uses the Python packages pinned in `requirements-lock.txt`, including NumPy, pandas, SciPy, statsmodels, scikit-learn, PyYAML, Matplotlib, and pytest.

Participant-level datasets and identifiers are not stored in this public repository. Public figures and evidence files are generated from committed aggregate outputs.

## External submissions

Competition-ready abstract and research-report prose is intentionally not stored in this repository. Any external submission should be written and verified independently by the applicant, accurately describe all assistance, and comply with the rules of the receiving organization.
